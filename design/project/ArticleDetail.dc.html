Training for your first marathon doesn't have to be complicated. Start with a base of easy running, then layer in one long run per week.

Build your base

Spend the first four weeks simply getting used to running on consecutive days. Keep the pace conversational.

  • Three easy runs per week
  • One rest day between harder efforts
  • A weekly long run, adding 10% distance each week

Sign up for a local beginner training group if you want structure and company.
